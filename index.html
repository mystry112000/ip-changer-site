IP Changer

Automatically rotate your IP address using the Tor network

Every few seconds — a new IP. Stay anonymous, bypass restrictions, test geo-blocked content.

How It Works ↓

How It Works

1

Tor Network

Your traffic bounces through three random Tor nodes (entry, middle, exit). The exit node's IP is what websites see.

2

ControlPort (9051)

The script sends a SIGNAL NEWNYM command to Tor's control port — Tor immediately picks a new circuit with a new exit IP.

3

Automatic Loop

This repeats every N seconds (you choose). Each cycle = fresh IP from a different exit node anywhere in the world.

        You → Tor Entry → Tor Middle → Tor Exit 🌍
                                        ↓
                                  New IP appears
                                        ↓
                                SIGNAL NEWNYM
                                        ↓
                              Tor picks NEW exit
                                        ↓
                                  Another IP!

All Commands — Explained

1. Install Dependencies

sudo apt update && sudo apt install -y curl tor jq xxd netcat-openbsd

Installs: curl (fetch IP), tor (the network), jq (parse JSON), xxd (hex auth), netcat (send signal)

2. Start Tor Service

sudo systemctl start tor

Starts Tor in the background. It listens on port 9050 (SOCKS proxy) and 9051 (ControlPort for commands).

3. Enable ControlPort (if not already)

echo -e "ControlPort 9051\nCookieAuthentication 1\nCookieAuthFileGroupReadable 1" | sudo tee -a /etc/tor/torrc && sudo systemctl restart tor

Without ControlPort, you can't send NEWNYM. This config enables it and restarts Tor.

4. Change IP — One Time

COOKIE=$(sudo xxd -ps /var/run/tor/control.authcookie | tr -d '\n'); printf 'AUTHENTICATE %s\r\nSIGNAL NEWNYM\r\nQUIT\r\n' "$COOKIE" | nc 127.0.0.1 9051; curl --socks5-hostname 127.0.0.1:9050 https://check.torproject.org/api/ip | jq -r .IP

Reads the auth cookie, authenticates to ControlPort, sends NEWNYM signal, then queries your new IP via Tor's SOCKS proxy.

5. Automatic Loop (Every N seconds)

while true; do COOKIE=$(sudo xxd -ps /var/run/tor/control.authcookie | tr -d '\n') printf 'AUTHENTICATE %s\r\nSIGNAL NEWNYM\r\nQUIT\r\n' "$COOKIE" | nc 127.0.0.1 9051 IP=$(curl -s --socks5-hostname 127.0.0.1:9050 https://check.torproject.org/api/ip | jq -r .IP) echo "$(date) - New IP: $IP" sleep 10 done

Infinite loop: change IP → print it → wait N seconds → repeat. Change sleep 10 to any interval.

6. Route Your Browser Through Tor

# Firefox: Settings → Network → Proxy → SOCKS5 → 127.0.0.1:9050 # Or via terminal: export http_proxy=socks5://127.0.0.1:9050 export https_proxy=socks5://127.0.0.1:9050 curl ifconfig.me # Now shows Tor exit IP

Set your system/browser proxy to Tor's SOCKS5 address and all traffic flows through Tor.

7. Install as System Service (Runs at Boot)

sudo cp change_tor_ip.sh /home/$USER/ sudo chmod +x /home/$USER/change_tor_ip.sh sudo cp change-tor-ip.service /etc/systemd/system/ sudo systemctl daemon-reload sudo systemctl enable --now change-tor-ip.service

Installs as a systemd service so IP rotation runs automatically on boot in the background.

8. Check Service Status

sudo systemctl status change-tor-ip.service

Shows if the service is running and the last few log lines.

9. Stop the Service

sudo systemctl stop change-tor-ip.service

Stops the IP rotation until you start it again or reboot.

Why Use IP Changer?

🛡️ Anonymity

Websites can't track your real IP. Each request can come from a different country.

🌍 Bypass Geo-blocks

Access region-locked content by switching to an exit node in the allowed country.

🧪 Web Scraping

Avoid rate-limiting by rotating IPs during automated data collection.

🔬 Pentesting

Test how your application behaves under different IPs without using a VPN.

Quick Start

git clone https://github.com/techchipnet/ip-changer.git cd ip-changer chmod +x ip-changer.sh sudo ./ip-changer.sh

Then enter your desired interval in seconds (default: 10). The script installs everything and starts rotating immediately.

Note: The script has two bugs — $HOME missing in change_tor_ip.sh:11 (should be $HOME) and the service file hardcodes /home/anil/ — edit it to your username.
